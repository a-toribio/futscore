# FutScore

Aplicación web en español para seguir partidos de fútbol en directo, alineaciones tácticas sobre el campo, clasificaciones, clubes, selecciones nacionales y fichas completas de jugadores.

## Características principales
- **Resultados en vivo y por fechas:** Seguimiento de las principales ligas europeas (LaLiga, 2ª División, 1ª/2ª/3ª RFEF, Premier League hasta League Two, Serie A, Bundesliga, Ligue 1), copas, Champions/Europa/Conference League y competiciones de selecciones nacionales (Mundial FIFA, Eurocopa, Nations League, Copa América, Clasificatorios).
- **Alineaciones tácticas interactivas:** Campo de fútbol visual con distribución exacta por líneas y bandas según demarcación y retratos oficiales de jugadores.
- **Fichas completas:**
  - **Clubes y Selecciones Nacionales:** Historia, estadio/sede, palmarés, convocatoria/plantilla, calendario pasado y futuro.
  - **Jugadores:** Biografía, estadísticas de temporada, selección nacional, trayectoria completa de clubes y retratos oficiales.
  - **Enfrentamientos directos (Cara a cara / H2H):** Historial multi-temporada entre equipos.
- **Buscador global:** Búsqueda instantánea de competiciones, clubes, selecciones y futbolistas.

## Cómo usar el proyecto en otro ordenador

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/a-toribio/futscore.git
   cd futscore
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Arrancar en modo desarrollo:**
   ```bash
   npm run dev
   ```

4. **Otros comandos útiles:**
   ```bash
   npm test        # Ejecutar tests unitarios (Vitest)
   npm run lint    # Comprobar reglas de linter (Oxlint)
   npm run build   # Compilar para producción (TypeScript + Vite)
   ```
